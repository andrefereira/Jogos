🧠 Lembra?

  • 2 é a parte IMAGINÁRIA (laranja)

⑧ Valor numérico e raiz

🧠 Lembra?

P(x) = x + 4
  • Troque o x por um número: x = 2 → 2 + 4 = 6. Esse é o VALOR NUMÉRICO.
  • Se o resultado for ZERO, o número é a RAIZ.
  • Em x − 3, a raiz é 3, porque 3 − 3 = 0.

⑨ As quatro contas

🧠 Lembra?

  • SOMAR: junte os vagões GÊMEOS.
    3x + 4x = 7x
  • SUBTRAIR: tire os vagões GÊMEOS.
    7x − 3x = 4x
  • MULTIPLICAR: o número de fora multiplica CADA vagão.
    2 × (x + 3) = 2x + 6
  • A JANELA: multiplica tudo e junta os gêmeos no fim.
    (x + 1)(x + 2) = x² + 3x + 2
  • DIVIDIR: é o contrário de multiplicar.
    (6x + 4) ÷ 2 = 3x + 2
  • A CHAVE: divide passo a passo. No fim sobra ZERO.
